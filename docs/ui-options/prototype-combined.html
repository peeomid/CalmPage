Design Philosophy

Good design is not just what it looks like and feels like. Good design is how it works.
— Steve Jobs

Design is not decoration. It is a decision about clarity, hierarchy, function, and respect for the reader's time.

1. Clarity is Kindness

Clarity removes friction. It helps people understand, act, and decide with confidence. In a reader app, the content should always win.

2. Settings Are Creative Tools

A theme should not be limited to light and dark. Users should be able to shape typography, spacing, code blocks, tables, tabs, and chrome into a preset they can save.

theme.reader.background = "#fbf7ed"
markdown.heading.scale = 1.28
ui.tabs.style = "fixed-scroll"

3. Keyboard First

The command palette should be the fastest path to files, open tabs, headings, settings, and presets.
