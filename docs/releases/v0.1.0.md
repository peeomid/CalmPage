# CalmPage v0.1.0

First public release of CalmPage.

## What is included

- Reading-first Markdown desktop app for macOS
- Folder library with workspace support
- Multiple file tabs
- Focus mode
- Table of contents
- Command palette
- Reader settings and theme presets
- Markdown rendering for `.md`, `.markdown`, and `.mdx`

## Main shortcuts

- `Cmd+K` command palette
- `Cmd+P` search files
- `Cmd+B` toggle sidebar
- `Cmd+J` toggle table of contents
- `Cmd+.` toggle focus mode
- `Cmd+[` and `Cmd+]` move between tabs

## Notes

This release is aimed at people who want a calm, keyboard-friendly way to read Markdown locally on macOS.
