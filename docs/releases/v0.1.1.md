# CalmPage v0.1.1

This release improves day-to-day reading and file navigation.

## Improvements

- Restores opened files when CalmPage starts again.
- Keeps the app visible on launch by using a more stable main layout.
- Adds manual folder refresh from the Library header and folder right-click menu.
- Shows a small, quiet sync status when folder lists or open files refresh.
- Refreshes already-open files when their content changes on disk.
- Adds right-click actions on open tabs:
  - Show in library
  - Copy relative path
  - Copy full path
- Adds a resizable Library sidebar with saved width.
- Auto-scrolls the tab strip so the active tab stays visible.
- Changes the main command palette shortcut to `Command-P`.
- Uses `Command-Shift-O` to open the command palette filtered to open tabs.

## Notes

- Existing app data and saved folders are preserved.
- Current builds target Apple Silicon macOS.
