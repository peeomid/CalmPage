# CalmPage v0.1.3

This release improves startup speed, tab switching, update status placement, and sidebar collapse behavior.

## Improvements

- Loads the active saved tab before the full folder scan finishes.
- Restores other saved tabs in the background after startup.
- Shows pinned files from saved paths before the full folder scan finishes.
- Restores tab reading position instantly, without visible scroll animation.
- Moves folder update status into a bottom-right toast so it does not push the tab bar.

## Fixes

- Fixes `Cmd+B` sidebar collapse so both the icon rail and Library panel fully hide.
- Keeps the sidebar collapse width at `0px` even when inline layout styles are active.

## Notes

- Existing saved folders, tabs, pinned files, workspaces, and reading settings are preserved.
- Current builds target Apple Silicon macOS.
