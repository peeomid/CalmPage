# CalmPage v0.1.2

This release makes important files easier to reopen and makes command palette path search faster.

## New

- Adds pinned files for Markdown files you open often.
- Shows pinned files above the Library file tree.
- Adds `Pin file` and `Unpin file` actions to file and tab right-click menus.
- Shows a small pin marker on pinned tabs.
- Adds a Pinned Files group to the command palette.
- Adds `!` command palette prefix to search only pinned files.

## Improvements

- Speeds up command palette path search when a pasted path points to a file that is not indexed yet.
- Searches likely folders near the pasted path instead of scanning the whole vault.
- Handles pasted paths with extra spaces or newlines more safely.
- Keeps tab reading position when switching away and back without showing a visible scroll movement.

## Notes

- Pinned files are saved locally on your Mac.
- Existing app data, saved folders, workspaces, and tabs are preserved.
- Current builds target Apple Silicon macOS.
